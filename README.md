# Caliceti di Bologna redesign

Responsive homepage prototype based on the selected third visual direction. It uses Caliceti's public restaurant, history and event photos, refreshed commercial-style food imagery, live product names and prices, and the existing page and order destinations. Food images are illustrative and are not presented as documentary photos of specific served plates.

Most navigation and commerce links open the current Caliceti site. The contact form is a front-end preview and points visitors to the existing contact form to send a message.

## Run locally

```sh
pnpm install
pnpm dev
```

The visual and navigation behavior can be reviewed at the root page. Source asset origins are documented in [ASSET_SOURCES.md](./ASSET_SOURCES.md).
